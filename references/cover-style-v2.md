# 系列听书封面 V2

默认风格 ID 为 `book-scene-editorial-v2`。以故纸观今主页截图为排版和构图参考，每期使用与本书相关的原创画面。

## 选定封面看点

围绕本期核心问题，先写两种构图和副题草案。每种写清正文依据、画面里的一个关键动作或物件，以及观众看完小图会想追问什么。可以分别表现人物作决定的一刻和决定带来的后果，也可以用人物关系与关键物件各讲一遍。选出缩小后最容易读懂、最能引出故事的方案，再分别制作两个发布比例。

标题提出本期问题时，画面和副题补一个具体的处境、选择、反差或代价。看副题和画面时，以第一次接触这本书的观众为准，检查能否用一句话说出眼前发生了什么或这期值得听什么。参考对标的视觉引导和空间安排，并用本期正文里的场景做原创构图。

## 文字层级

1. 整本解说可在上方或左上放大号分钟数字，紧贴较小的「分钟听完」。合集单集可以用选篇或主题交代本期范围。文字按底色选朱红、暖黄或米白等对比清楚的颜色。
2. 书名在上半部独立成块，使用笔画有力、易读的书法或粗笔大字。短书名可横排，长书名可分两至三行，按语义断行。
3. 书名下方只放一句小字，点出本期事件、处境或反差，最多两行。其余空间留给画面。

整本解说的分钟档位用 `studio.py runtime-label PROJECT` 核对。若改剪，传入最终成片实测秒数。口播有分钟文案时使用相同档位。缺实测时长时省略分钟文案。

## 画面层次与光色

- **用空间让画面丰富起来。** 写清近景用什么带入画面，中景谁在做什么，远景通过哪处建筑、地形或光影交代地点和时代。用门框遮挡、石阶透视、人物站位和远近的明暗等组织空间。近景特写也可以用前侧物件、主体和背景光影交代层次，空镜由有叙事作用的物件承担焦点。
- **让每处细节服务同一个看点。** 先定人物之间的动作、视线和距离，再选能说明处境的物件或材质，例如两人之间正在递出的包裹、被灯照亮的旧契据、门槛内外不同的石面和木纹。细节集中在观众需要看的地方，远处轮廓和文字区保持安静。缩小后仍能辨清关键动作或物件。
- **每期根据场景定光和色。** 写具体的主光来源、方向、照亮的主体部位和暗部保留的轮廓。说明大面积环境是什么颜色，哪一处用另一种明暗或冷暖拉开远近，点色具体落在人物、物件或文字哪里。比如用冷白月光洗亮院子，再用一盏暖灯勾出说话人的眉眼。白天、雨雾、火光和夜景各用情节需要的光色，和最近几期并排时应能从场景、动作或明暗构成认出本期。
- **文字嵌入画面。** 找一块纹理少且与字色对比清楚的区域，例如天空、墙面、雾气或暗部。写清书名、分钟或集号、副题的位置与大小关系，给脸、手势和关键物件留足空间。画面只呈现本期指定的文字，平台角标交给平台界面。

## 出图与验收

- 开始生成封面前按 [生图方式](../modules/image-generation/GUIDE.md#生图方式) 确认本次使用的工具；同一已确认的发布计划沿用记录。
- 按 [生图提示词清单](../modules/cover-design/GUIDE.md#生图提示词怎么写) 分别设计并生成 3:4（1080×1440）和 4:3（1440×1080）两张成图，各自安排文字、主体和安全边距。
- 缩到手机主页三列缩略图大小，与近期已发封面同尺寸并排。先检查书名和分钟或集号是否醒目，再检查副题与关键动作或物件是否好懂、主次和明暗层次是否保留。本期要有可辨认的场景或人物动作，系列可沿用字体和文字层级。
- 回看两种比例的完整画面，检查光线有没有把视线引向事件，近中远层次和细节有没有讲明场景，同时核对人物肢体、时代细节、文字字形、像素和安全边距。按小图和原图中发现的问题分别调整。
- 在 `cover/brief.json` 记录两种草案及选定理由、正文依据、标题与封面分工、场景和光色、两张图实际使用的提示词、参考图、成图路径和并排复核结果。改版使用带版本号的记录和成图路径，并更新发布包引用。
