# 封面 V2 候选
逐张封面研究支持分钟、书名和主题的可见层级。阿正保留当前生产发布规格，本页供候选试样。

1. 先做缩略图读字测试。书名最大，分钟作为收听投入提示，副题只承担一个问题或行动方向。
2. 依据题材选一个动作或意象。人物题选可见处境，历史题用制度关口或地点，观念题用具体器物或反差。控制高反差文字底色。
3. 对照视频标题。封面可补书名、动机或结果，也可延续同一主题。审核时明确它承担哪一项。
4. 在正式发布比例中验证裁切、字号和移动端可读性。分钟文案在实测片长后复核。将置顶、付费角标与原设计分开。
5. 为可比作品保存同题强化和信息互补各一版，记录曝光条件。现有研究无法证明某种配色更能提高点击。
