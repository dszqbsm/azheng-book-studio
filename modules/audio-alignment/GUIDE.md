# 用户试听通过后的转录与文字校正

默认顺序：用户确认最终音频无误 → Coli本地转录 → Agent对照同版本定稿校正识别文字 → 基于真实语音时间制作分镜。文稿核对和错字处理由Agent完成，不交给用户逐条审阅。

用户试听确认作为本轮音频内容通过的依据；在没有其他异常证据时，识别出的同音字、人名、古文、数字和标点差异按定稿修正，不因ASR差异自动要求用户重新试听或重新配音。记录最终音频和定稿哈希，防止对错版本。

原始ASR JSON不可覆盖。另存校正转录与修改记录，注明“按用户已确认音频对应定稿校正文字”，不称Agent逐字试听通过。校正采用原文完整句段，保留原始token和时间戳作为证据；字数发生变化时，不把旧token时间逐字硬套给新文字。仅在能可靠映射的真实句段边界上建立cue，不按字数平均分配伪精确时间。

若整句缺失、长段错位、异常重复或时间戳不足使边界不能可靠映射，Agent先检查版本和识别结果，必要时局部重转录或检查相应音频，记录未解决区间；不得默默补写没有声音证据的时间戳，也不把异常清单直接作为用户作业。只有确认音频本身有问题才进入局部修补，新的收费调用遵循本期授权范围。

实现状态：当前脚本可采集原始ASR并生成差异报告；本指南规定Agent后续处理方式，不代表自动句段对齐、校正转录及SRT脚本已经实现。具体产物必须按真实执行报告。

## 字幕分句与引用排版

使用 scripts/subtitles.py 的 caption_boundaries 选择切点。普通正文在句末及中英文逗号、分号处分卡，每卡显示一个短句。单卡引用保留成对引号。含逗号或分号的诗句和其他跨卡引用也按短句拆分，只在展示层去掉外引号，保留原始对齐稿。进剪映前检查普通正文跨句、悬空引号、文字覆盖和时间重叠。句末缺可靠词元时回查相邻转录证据。
