# Gemini 开头钩子候选
输入书名、核心问题、可靠证据和目标受众情境。每次生成三种原创开头，附下一章第一段的承接，禁止将想象或演绎写成事实。

| 机制 | 如何写 | 样本 |
|---|---|---|
| 现实困境 | 给一个普通人正在做的动作或判断，再引出书能回答的问题 | V001、V008 |
| 人性揭示 | 先展示表面动机，再留出角色真正顾虑的悬念 | V031 |
| 历史悬念 | 给一个具体决策或因果反常，正文交代证据 | V002、V017 |
| 人物命运 | 从当事人看得见的处境、行动或代价切入 | V006、V045 |
| 结果倒推 | 先写一个有证据的结果，再回到关键条件 | V050、V057 |
| 认知反转 | 先指出熟悉印象，明确哪条原著证据迫使重读 | V009、V015 |
| 故事冲突 | 交代人物目标与阻力，留出为何要做该选择 | V054 |

审稿时分别填写首句、书名、首个故事、承诺和正文承接。书名时间依成片实测。
