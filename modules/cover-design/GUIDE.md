# 讲书封面设计

按 [系列听书封面规范](../../references/cover-style-v2.md) 比较两种场景构图和副题草案，定下能让观众一眼看懂本期看点的方案。按本期已确认的生图方式分别完成 3:4（1080×1440）和 4:3（1440×1080），核对小图、原图和实际尺寸后与其他发布内容一起交付。工作记录保存在 `cover/brief.json`，同时注明书名、核心问题、发布标题、最终实际时长和风格 ID。 [发布流程](../publishing/GUIDE.md)

## 生图提示词怎么写

每个比例都写一份完整提示词，并写清以下信息。

1. **故事场面和第一眼的焦点。** 交代时间、地点、人物的站位和动作、对视方向、关键道具，以及观众应先看到哪里。比如「站在门槛外的小倩压低声音示警，门内的宁采臣转头听她说」，连同动作和对象一起写进提示词。
2. **近景、中景和远景。** 逐层写清物件、人物在画幅中的位置和大小，以及远处环境怎么交代地点。写出能让场面真实起来的少量细节，如青石上的反光、门漆的磨损或远处院墙后的竹影。
3. **光源和具体配色。** 写清光从哪边来、照亮哪张脸或哪个物件，哪里留暗、哪里要保留轮廓。分别指定环境主色、用于区分空间或人物的辅助色，以及点色放在什么地方。
4. **准确文字和版式。** 逐行列出实际要显示的字，指定最大字的书名、分钟或集号、短副题的位置、颜色及占用区域。说清文字背后是什么，脸和关键动作留在哪一侧。换比例时重新描述文字区和人物布局，留足安全边距。

## 聂小倩提示词示例

以下适用于 3:4 竖封面的方案示例，文字和场面按本期定稿确定。

```text
制作 3:4 竖版讲书封面。画的是蒲松龄《聂小倩》里小倩深夜回荒寺提醒宁采臣避险的一刻。用原创古典设色志怪插画，保留旧木、青石、素衣和淡墨竹叶的材质差异。

近景在右下角留一截磨旧的木门框与青石门槛，石阶上的月光把视线引向中景。画面中部偏下，小倩穿灰蓝素衣，立在门槛外，身体微向前倾，抬眼低声示警。宁采臣在门内左侧转头听她说话，两人隔门槛相望，侧脸和手部动作清楚。远景露出空院、矮墙和几竿细竹，竹叶比人物轻、比近处门框淡。

冷白月光从院墙左上方斜落，照亮石阶、院中竹影和小倩衣袖。门内一盏琥珀色油灯照出小倩的眉眼和宁采臣转过来的侧脸，让两张脸成为画面焦点。院子以灰蓝为主，旧门框和室内留木棕深暗部，朱红只用于集号。

画面上方的灰蓝墙面留作文字区，纹理放淡。左上小一号朱红字写「第2集 · 聂小倩」，其下用米白粗笔写最大字「聊斋志异」，再下用一行清楚的浅米色字写「她先示警，才开口求救」。全图只排这三行。人物面孔、手势和门槛完整露出，文字和人物都留出边缘余量。
```
