# V1 与 V2 候选对照
| V1 规则 | 本轮处理 | 依据或缺口 |
|---|---|---|
| 书名加现实问题、标题兑现正文 | 保留，样本观察支持；新增标题封面分工 | V001、V003、V009 对照 |
| 一期一个贯穿问题 | 保留，允许复杂叙事靠同一个因果问题收束 | V028、V050；全量话题数未编码 |
| A–H 主模式及证据章节卡 | 保留，增加组合示例 | V006、V037、V050 |
| 约 300 汉字/分钟 | 保留为预算，新增实际时间复盘 | 50 条正文中位约 296，依转写口径 |
| 开头用反差、故事或现实入口 | 增加报书名、假设、展开故事分别标注 | V003、V033；最佳秒数待实验 |
| 结尾回扣 | 保留，新增按场景选择 CTA | V008、V037、V067；无转化数据 |
| 图书推荐作内容延伸 | 保留。新增免费完整解读和会员深化候选 | V012 可见原著建议，会员深度与转化待证 |
| 六维人工评分 | 生产继续 V1，新增十维 1–10 分影子量表 | 初稿评审试用，阈值待验证 |

新发现主要来自封面分钟层级、同书不同视频和可定位的开头锚点。对增长、留存、成交的判断均为待验证假设。
