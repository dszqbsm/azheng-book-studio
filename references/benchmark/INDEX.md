# 对标资料库使用说明

本目录存放用户提供的「故纸观今」10篇逐字稿，以及由这些材料提炼的研究结果。

## 目录说明

- `transcripts/`：**10篇逐字稿原件，不做清洗、不直接用于逐句改写。**
- `analysis/ten-sample-analysis-v1.md`：逐篇拆解、横向结论及待验证假设。
- `metrics.csv`：逐字稿自带互动数据和统一计算的基本指标。
- `metadata.json`：机器可读取的元数据与未知字段。
- `../writing-dna-v1.md`：每次讲书创作的核心写作规则。
- `../narrative-structures-v1.md`：按书籍类型选择的结构模式库。

## 建议读取顺序

**日常写稿**：优先 `../writing-dna-v1.md` → `../narrative-structures-v1.md` → 本书资料。一般无需读取10篇对标逐字稿。

**优化写作 Skill**：先 `analysis/ten-sample-analysis-v1.md` → 遇到争议再按作品读取 `transcripts/`。

**复盘是否应该补资料**：先 `metrics.csv` 查看缺失的发布时间、播放量；增量样本优先围绕某个假设收集，不应盲目扩张。

## 数据口径说明

1. 时长为源逐字稿内提供的标注时长，非重新测量原视频。
2. 汉字数是从 `## 完整逐字稿` 后的正文里计算 CJK 字符所得，含章节小标题，前一轮人工统计可能采用不同口径。
3. 四篇互动较小的稿件，原文件中均说明可能发布不久，不能据此评断内容效果。
4. 逐字稿包含自动语音转写误差；本资料库没有对历史真实性进行逐条复核。

## 资料管理

- 保留原件文件名，避免因替换文本导致后续证据定位失效。
- 新增样本放入 `transcripts/` 后更新 `metrics.csv` 和 `metadata.json`。
- 上游来源是平台他人内容，仅用作内部研究；实际作品使用原著和可用史料创作自己的解说稿。
