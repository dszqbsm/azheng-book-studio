# 选书评分候选
每项 0–4 分，0 表示证据不足，2 表示可用但有缺口，4 表示已核证并能直接进入策划。合计 20 分，分数供同轮比较。

| 维度 | 4 分条件 |
|---|---|
| 主题 | 一个普通人能复述的具体问题，并解释为何本书合适 |
| 来源 | 有版本、页码或章回，可定位核心主张 |
| 叙事 | 至少有三个承担不同功能的故事或例证，并有可讲的行为和后果 |
| 体量 | 能拆成若干推进单元，按配音预算可兑现片长 |
| 区别 | 能说明与已有同书、同题视频的核心判断或案例有何不同 |

15 分以上可进入影子样片。来源未核证的核心事实先补资料。商品和会员适配另行记录，依据版本、实际入口及额外阅读价值，不合入选书总分。阈值是项目试验起点。
