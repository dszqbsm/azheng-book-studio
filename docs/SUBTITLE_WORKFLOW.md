# 默认字幕流程（2026-11-05）

本规则取代V0.1文档中“默认无字幕”的历史约定，仅适用于azheng-book-studio讲书项目。用户明确要求无字幕时仍以本次要求为准。

标准生产链：定稿→正文配音→测时后生成开场→合并→用户试听确认→本地转录→Agent按定稿校正→真实时间短句字幕→分镜配图→含黄色大字幕的剪映草稿→效果检查。字幕可以在配图期间准备，但交付草稿前必须完成。

默认样式：黄色粗体9号、黑色描边、下方居中、位置-0.60、自动换行。自然断句，不硬切词；末尾省略停顿标点，保留书名号、引号和句内标点。字幕正文应保持原文完整，时间来自实际语音。所有修改另存新版本。

接口：项目subtitles/captions.json含audio_sha256、script_sha256及cues（start/end/text）。draft入口读取配置并创建字幕轨道；缺文件、版本不符、无效时间时报错。项目book.json可明确设置subtitles=false。短句拆分和真实时间对齐仍由Agent负责，导出代码不会把长段落自动变成合格字幕。

验证：11项单元测试通过；使用《菜根谭》614条已校正短句实际运行新版draft入口，成功生成本地book_9e634b954cca草稿。未覆盖已安装剪映工程，未声称在剪映播放验收。此次导出是流程验证，用户当前查看的v06工程保留。
