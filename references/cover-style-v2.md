# 系列听书封面 V2

默认风格 ID 为 `book-scene-editorial-v2`。以故纸观今主页截图为排版和构图参考，每期使用与本书相关的原创画面。

## 设计判断

以单张封面的美感、内容表达和缩略图可读性决定方案。系列可以沿用字体、配色或场景类型，也可以依内容调整，不要求每本书刻意求异。与已发布封面相似本身不构成重做理由，换色也不能代替构图改进。

参考对标封面时，先观察文字与场景的面积关系、人物动作、空间层次、光线和视觉焦点，再结合本期定稿设计。借鉴其构图与叙事方法，不把某一本的纸色墙面、门廊背影或冷蓝夜景固化为全系列模板。

## 文字层级

1. 整本解说可在上方或左上放大号分钟数字，紧贴较小的「分钟听完」。合集单集可以用选篇或主题交代本期范围。文字按底色选朱红、暖黄或米白等对比清楚的颜色。
2. 书名在上半部独立成块，使用笔画有力、易读的书法或粗笔大字。短书名可横排，长书名可分两至三行，按语义断行。
3. 书名下方只放一句小字，点出本期事件、处境或反差，最多两行。其余空间留给画面。

整本解说的分钟档位用 `studio.py runtime-label PROJECT` 核对。若改剪，传入最终成片实测秒数。口播有分钟文案时使用相同档位。缺实测时长时省略分钟文案。

## 画面与配色

- 以与本期内容直接相关的空间、事件或物件为焦点。文学可用门廊、街巷和人物背影；历史可用公堂、城池和关键证物；思想、经济可用书房、案桌或一个能说明问题的场景；科幻可用冷色远景。
- 题材决定色调。明亮场景可用暖白、纸色或自然天光，文字选墨黑、深棕或朱红；夜景和深蓝场景可用米白或暖黄字。按场景安排人物位置与景别，人物可以是小比例全身、背影或剪影。
- 上半部留可读的文字区，下半部或画面一侧用场景交代内容。按具体画面调整位置，避免亮部、细碎纹理和人物脸部干扰读字。排除平台置顶、付费、点赞和播放状态等界面元素。

- 从定稿选一个具体场景，说明人物正在经历什么，以及动作、关系或关键物件怎样传达本期问题。按场景需要确定人物大小和冷暖配色。空镜也应有明确的空间或物件焦点。
- 将文字安排在场景中的墙面、天空或暗部等适合阅读的位置，兼顾画面完整性。避免大面积文字底板挤压主体，或只放一个缺少情节联系的小人物作装饰。
- 小字优先提供具体处境、行动代价或事件反差，并核对正文依据。可以采用问题或概括，但要与画面共同表达内容，避免泛泛感悟。《围城》可用争吵后独坐的人物、未收好的行李和六点老钟，配“钟响六下，早已错过”。这是本书的设计示例，其他书按各自内容设计。

## 出图与验收

- 依此规范分别设计并生成 3:4（1080×1440）和 4:3（1440×1080）两张成图，各自安排文字、主体和安全边距。
- 缩到手机主页三列缩略图大小，检查能否先认出分钟数字和书名，再读懂小字；同时检查中文笔画、文字与背景反差、实际像素和两版裁切。
- 在 `cover/brief.json` 记录档位、书名、小字、场景、配色、实际提示词、参考图、风格 ID 和成图路径。
- 分别检查两种比例的完整构图和缩略图，确认主体有足够视觉分量，场景有层次，文字与画面相互配合，人物肢体、关键物件和时代细节合理。必要时与用户提供的对标图并排观察，按上述具体问题修改，不以颜色是否不同判断优劣。
- 设计记录同时写明正文依据、标题与封面的分工、构图选择及实际目视复核结果。保存每张图实际使用的完整提示词。改版使用带版本号的记录与成图路径，并更新发布包引用。
