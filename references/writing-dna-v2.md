# Writing DNA V2.0
状态：2026-11-10 经用户确认，默认用于新讲书文稿。

- 先用选书卡限定一个可在一期内回答的问题，并为每个核心判断准备可定位的原书或史料。
- 写出标题与封面的分工。标题交代对象或具体问题，封面可补书名、人物处境或行动方向。发布规格沿用现有四平台规则。
- 从可辨认的场景、具体事件、人物选择或可解的反差进入。区分演绎、史料和原文。选题卡记录预计报书名和首故事，交付后用实测时间复盘。
- 长篇可以从人物命运转向原书体例，也可以用群像、制度关口或概念阶梯推进。每个关键例证应回答不同问题，并给下一节留下必要性。
- 每章检查可听性和证据。解释一个陌生术语后，用动作、后果或明确例证收住。情绪转换随证据发生。
- 结尾直接回答开头，再从关注、评论、收藏或延伸阅读中选择适用动作。商品和会员按真实资料及本期授权处理。
- 初稿预算可沿用 V1 每分钟约 300 字。全片、章节与封面分钟承诺以成片和实际音轨复核。

来源见 [68 条研究](competitor-research-68/reports/competitor-research-final.md)。使用 [质量量表](script-quality-rubric-v2.md) 审稿。

## 按书型设计正文

先按本期实际切入角度选一个主要书型，再选 A–H 主模式。混合题材可以借用其他书型的局部手法。

| 书型 | 正文推进 |
|---|---|
| 文学叙事 | 人物处境、选择、后果。每章让人物进入一个新处境。 |
| 历史与制度 | 围绕同一个疑问，用时代关口或不同人物的案例逐层解释成因、利益冲突与结果。 |
| 人物传记 | 选取改变人物命运的节点，讲清当时的选项、取舍和代价。 |
| 思想与处世 | 从具体两难出发，按理解顺序引入概念，给核心概念配原文证据和可理解的案例。 |

开头留一个正文能用证据回答的问题。正文每章推进一个变化或回答一个子问题。必要时用一两句现代类比讲清陌生概念，随后回到原著或案例。结语先用正文的具体细节回收开场问题或画面，再展开现代生活引申。
