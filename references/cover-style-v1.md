# 固定封面风格 V1

风格ID：historical-cinematic-ink-gold-v1。以《了凡四训》已确认封面为视觉基准，今后复用视觉语言，按每期主题更换人物、书名与问题，不能照搬袁了凡形象到其他人物。

- 历史写实、电影海报质感；墨黑与深青背景，暖琥珀侧光，金色书法书名与米白问题文案。
- 人物位于右侧，书名与核心问题占左侧或中下方；使用本期已确认的人物参考，时代、服饰与年龄对应内容。没有人物的书籍可使用相关书卷或场景，不强行捏造历史肖像。
- 书名为第一视觉重点，问题用一句简短文案、最多两行；小字“XX分钟读懂经典”使用最终实际时长的四舍五入分钟数。不得夸大效果，不额外添加品牌、平台logo或水印。
- 背景可用木窗、书卷、庭院等与本期内容一致的元素；保持简洁，文字不遮脸，四边留安全区，缩小后仍能辨认书名与问题。
- 只交付两张：3:4（1080×1440）及4:3（1440×1080）。分别排版，不能把竖版直接拉伸或裁掉文字充当横版。四平台复用这两张，不再默认生成9:16、6:7等版本；平台展示可能另行裁切，上传时检查预览。
- 使用宿主生图工具生成完整成图，检查中文、人物、构图与实际像素。新一期参考本期素材；不要把固定风格解释为固定所有项目的分镜画风。
- 保存实际提示词、参考图路径、成图路径与尺寸。修改另存版本，保留旧封面。
