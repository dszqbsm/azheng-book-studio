# 素材放置与字段

| 素材 | 路径 | 记录要点 |
|---|---|---|
| 逐字稿 | `transcripts/V001.md` 至 `V068.md` | 保留原件，尽量提供真实时间戳，注明是否全稿 |
| 封面 | `covers/V001.jpg` 至 `V068.jpg` | 保存原始比例及实际 JPEG，保留采集依据 |
| 评论 | `comments/V001.csv` 等 | 建议字段 `comment_id,captured_at,text,likes,sampling_method`，去除不必要的个人信息 |
| 视频截图 | `video-stills/V001/` 等 | 使用真实时间戳命名，说明来自哪一版视频 |
| 元数据 | `metadata.csv` | 从模板复制，UTF-8 或 UTF-8 BOM，表格中的空值保持空白 |

同一本书共用 `book_id`（如 B001），每个不同的视频使用独立 `video_id`。以原平台真实标题填 `title`。时间用带时区的 ISO 8601，如 `2026-11-09T12:00:00+08:00`。只有日期时在 notes 中记录日期精度，完整时间字段留空。计数用非负整数，精度或来源限制写入 notes。时长使用真实秒数，可含小数。已确认的会员和置顶状态填 `true` 或 `false`，未知留空。文件列用文件名或相对本目录路径。商品链接按实际观察填写。缺文件时其路径列留空，校验器仍会按编号清点。

原始素材和已填写的本地元数据由 Git 忽略。模板可随仓库分发。本目录校验仅检查入库格式、资产非空与引用一致性。完整稿、图像解码、封面目视与来源核验在逐条研究时完成。
