用 `queue` 输出任务清单。成图回填分镜后用 `images` 检查。

## 生图方式

开始实际生图前，如果用户本次未指定方式，请用户选择：

- **Codex 内置生图（`codex`）**。用宿主图像工具逐镜出图，按本镜要求传入角色或风格参考图。
- **DevPoolAi · gpt-image-2.6（`devpool`）**。用已有凭据调用中转站，支持纯文本和参考图。

收到选择后运行 `studio.py image-backend PROJECT --backend codex` 或 `studio.py image-backend PROJECT --backend devpool`。选择写入当前版本目录的 `images/backend.json`。不带 `--backend` 可查询记录。当前请求已明确指定方式时直接登记；同一个已确认的生图计划中断续跑时沿用记录。新一期或独立生图任务按本次指示选择，旧试图和全局偏好不能代替本次指示。只做分镜、队列或提示词可以直接推进。所选服务失败时，报告原因与未完成镜头，换用另一方式前请用户选择。

## DevPoolAi 调用

使用已配置的媒体 Python 运行 [devpool_image.py](../../scripts/devpool_image.py)。`check` 查询模型列表，确认 `gpt-image-2.6` 可用。脚本从进程环境变量 `DEVPOOL_API_KEY` 取密钥，Windows 下也可复用系统级同名变量。密钥保留在本机环境，不写入项目、命令参数或日志。

```text
PY <技能目录>/scripts/devpool_image.py check
PY <技能目录>/scripts/devpool_image.py generate --prompt "<本镜提示词>" --out "<本镜PNG路径>" --size 1280x720 --quality medium
```

- 纯文本请求使用 `POST /v1/images/generations`。有计划内参考图时，核对实际文件，每张用一个 `--reference "<参考图路径>"` 传入，脚本改走 `POST /v1/images/edits`。发送的是图像数据。提示词中的「图1」等编号按实际上传顺序对应；同一角色同一年龄阶段优先用已确认的基准图。
- Windows 如果 Clash TUN 仍接管域名连接，用 `Get-NetRoute -AddressFamily IPv4 -DestinationPrefix 0.0.0.0/0` 查正常出站网卡的 `InterfaceIndex`，在 `check` 或 `generate` 子命令前加 `--interface-index <索引>`。仅该 API 连接绑定网卡，保留 HTTPS 证书校验。
- 1280×720 已实测为 16:9。尺寸跟随本镜分镜比例。及时检查实际尺寸、人物、动作、道具、构图和边角字样；试图另存，正式成图通过后再登记。付费请求发生超时时先核对是否已有结果，避免重复请求。

《聊斋志异》等志怪题材可选用[古典设色志怪](../../references/visual-styles.md#古典设色志怪)。分镜使用 `--style classical-zhiguai` 时，生图任务会带上工笔线条、矿物色和场景中的反常变化等画风描述。审核逐镜提示词时，按本期故事核对服饰与道具。

新分镜配图默认 16:9 横幅，标准尺寸 1920×1080。同一比例的其他分辨率也可用。生成时在工具中选择横幅比例，并在逐镜提示词里明确写出 16:9 横构图。项目如有明确的其他比例，在 book.json 的 image_aspect_ratio 设置，生成分镜时写入 storyboard.json，再由 queue 传给生图环节。手工编写新分镜时也在 storyboard.json 记录该字段。回填前检查实际像素比例。接续没有比例字段的旧分镜时，沿用该期原提示词和参考图的比例。

用户要求继续配图或生成图片时，默认完成当前项目全部缺失镜头，逐张使用已选方式生成，保存到项目 `images` 目录，检查后登记分镜。已有有效图片保留在原所属镜头。用户只要求试图或指定数量时，以本次授权范围为准。分批执行时沿用选择，持续完成本次剩余队列。服务失败或额度限制时记录进度。人物有参考图时用于后续同角色镜头，同时保留本镜独立外貌描述。

- 每个分镜必须带来可辨认的新画面信息，例如新增动作、表情变化、人物关系、关键物件或场景变化。相邻两镜缺少新增信息时合并为一镜，按原有真实语音时间覆盖两段，保留口播和字幕时轴，允许延长展示。只换机位、景别或轻微构图时，以是否增加叙事信息判断。禁止把同一张图绑定到任何两个分镜；跨段回访若必须保留切点，设计并生成有新增信息的独立画面。

分镜配图使用连贯的满幅构图。提示词应写明地面、家具或自然前景按场景透视延伸到画框底边，不要求为字幕留出底部空间。字幕由剪映独立轨道叠加。验收时检查底部是否出现横向接缝、暗带、模糊遮罩或字幕底板，发现此类问题应修正后再登记。该规则同样适用于手工撰写的提示词和参考图生成。

- 先写明每镜新增的可见事件，再用真实语音时间落切点。生图前查相邻镜及全片同事件镜头，每小批出图后并排复核。发现近似画面，合并相邻镜或重做独立画面，同步更新分镜表和生图队列。人物参考可用于造型连续；同一成图只用于所属镜头。交付时检查各镜文件路径和内容哈希均唯一。
